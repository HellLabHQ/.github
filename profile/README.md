<h1 align="center">HellLab</h1>

We’re building **HellLab MAX** for developers who ship compiled software and want to make proprietary code harder to reconstruct or modify.

Right now we’re getting **Trial #003** ready for independent review. It asks a specific question: can someone recreate the behavior of three protected functions and pass a set of inputs they haven’t seen?

- [Explore HellLab](https://github.com/HellLabHQ/HellLab) for the project overview and technical notes.
- [Read the Trial #003 brief](https://github.com/HellLabHQ/HellLab/blob/main/docs/trial-003.md) to see how we’ll evaluate the results.
- [See what’s next](https://github.com/HellLabHQ/HellLab/issues/1) on the roadmap, or follow development on [Telegram](https://t.me/HellLab).
